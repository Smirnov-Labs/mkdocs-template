# User Journey Planning

## Overview

Product requirements organized into Epics and User Stories. Each epic is a large feature or capability; each user story is an individual deliverable unit.

## Structure

```
Epic
├── User Story 1
├── User Story 2
└── User Story 3
```

## Epic Registry

| Epic | Description |
|------|-------------|
| EP01 — Title | Short description |
| EP02 — Title | Short description |

## Creating a New Epic

1. Copy the epic template to a new file (e.g. `EP01-authentication.md`).
2. Fill in user stories and acceptance criteria.
3. Add the epic to the navigation in `mkdocs.yml`.
